### 1. [Team Artwork Generator](https://firsttothefinish.com/pages/art-generator "Art Generator")
This project was coded using the following languages: JavaScript, Shopify Liquid, CSS5, and HTML5. It was designed completely web-based, so no external system would need to be running to reduce cost on the company due to limitations in budget. Implemented in early 2026.

#### Project Overview and Goals
- Produce customized art designs for each customer based on a few of their personal details (Name, Mascot, Team Abbreviation, Logo, and Colors).
- Reduce the workload on the Graphics Department to ensure more efficient timeframes.
- Provide more consistent designs for customers to choose from.
- Provide color options based on core colors (chosen by customer) so designs are production ready.
- Provide art options for each core sport. (Currently ready for Track & Field, Cross Country, and Football)

#### How It Works
- Customer or Employee can enter key details based on the criteria needed (Name, Mascot, Team Abbreviation, Logo, and Colors).
- (Optional) Users can then apply filters based on sports to ensure faster load times and more-focused art options.
- User generates art using the Generate Art button.
- Wait for the designs to load.
- Each design is download ready and has options to see how each color would look on each color garment.

#### Project Cost

- External Cost: $0.00
- Hosting Cost: $0.00 (Built into cost of a hosted Shopify site)

#### Project Results Since Launch
- 3 active sport designs ready.
- 100+ designs created and used in past and dozens in use for active team stores.
- Improved timeframe for creation of team stores. (no longer waiting on Graphics department to create designs)


### 2. [Team Tent Designer](https://firsttothefinish.com/pages/tent-builder "Tent Builder")
This project was coded using the following languages: JavaScript, Shopify Liquid, CSS5, and HTML5. External APIs are made for emailing, pdf storage, and order readiness. Implemented in Fall of 2024 with dozens of fixes and feature updates. 

#### Project Overview and Goals
- Create an easy-to-use tent designer to increase speed in order creation.
- Create a way for sales representatives to design tents for prospective customers.
- Produce faster and easy to replicate designs for the Graphics Department to speed up art proof timelines.
- Provide the customers a way to see how many options they have to choose from for tent creations.
- Ensure true flexibility in design creation for the sales representatives and customers.
- Allow customers to design and order custom tents directly off the website.
  
#### How It Works
- User starts at Tent Setup Options (click this button to edit your tent options)
  - Here you choose your tent size, frame type, and if walls are included.
  - Price is clearly displayed to ensure proper cost of the product.
  - After changes have been made, make sure to press the save changes button.
- User starts design at the Front Peak of the tent.
- User then chooses a color, can be any of the default swatches or a full-custom color option using a color chart.
- (Optional) User then adds text to the current location.
  - Text can be rotated, resized, and moved to fit wherever you need it to.
  - Text font, color, and an outline can also be adjusted to match needs of the user.
  - Text can be removed by deleting the text in the input field or by selecting the text and using the delete key.
- (Optional) User then adds art to the tent by uploading any image file (svg, jpeg, jpg, png, etc.)
  - Art can be rotated, resized, or moved to fit wherever you need it to.
  - Multiple images can be added at the same time.
  - Images can be reordered for layering purposes by dragging and dropping in the art-preview section.
  - Images can be given a default size option by using the dropdown below each image in the art-preview section.
  - Images can be removed using the art-preview section or by selecting the image and using the delete key.
- (Optional) Users can add notes to artist for this given section
- Hit the next key or select the next location to continue designing.
- Repeat the steps above for each section
- After all designing is finished, hit preview to get a full overview of the designed product.
- If edits need to be made, you can go back to editing and make adjustments.
- When editing is complete, fill out the customer information and press submit.
  - This does not mean an order has been placed but allows the sales representatives to get in contact with you for further leads.
  - This does send an email to the user and to the customer service team for lead purposes.
  - The design is then added to the cart and ready for order if you choose to purchase it immeditately.


#### Project Cost
- Cost per use: $0.00001
- PDF Storage Cost: $0.00001 per file stored
- Email Cost: $0.00 up to 10000 emails a month free, $0.0002 per GB data used after
- Hosting Cost: $0.00 (Built into cost of a hosted Shopify site)

#### Project Results Since Launch
- Thousands of designs made by employees.
- Hundreds of designs made by customers.
- Improved tent design workflow by 61%. (Graphics department only needs to handle designs for ready-to-place orders now)
- Improved tent leads to order conversion by 117%. (Number of tents sold prior years to years since implementation)
